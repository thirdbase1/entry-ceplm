# Entry Agent

Entry Agent is an open-source reference app for building and running background coding agents on Vercel.

The agent does not run inside the VM. It runs outside the sandbox and interacts with it through tools.

===== FILE: docs/contracts =====
PATH:docs/contracts
Q: List the three Entry permission modes.
A: Ask | Auto Accept | Full Access

Q: Describe the durable run state machine.
A: RUN_CREATED -> STEP_STARTED -> MODEL_CALLED -> TOOL_REQUESTED -> TOOL_RUNNING -> TOOL_COMPLETED -> VERIFICATION

Q: Where must permissions be enforced?
A: Below the model layer: Permission Engine before Tool Executor.
